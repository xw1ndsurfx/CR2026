# Weapon skills HUD

Active, unlocked techniques for the equipped weapon appear as compact icon slots directly above the actual hotbar position. Each technique can use a PNG from `resources/spells`; the equipped weapon icon is the fallback. Names and combat details appear in tooltips, while remaining cooldown seconds and progress appear on the slot. Visible bitmap glyph metrics keep the countdown readable with the global Empire 7 size-10 setting. No keyboard shortcuts or mastery costs change.

Weapon Mastery Editor has a **Weapon skill quickbar** dialog for enabling the bar, slot size, slot spacing, maximum columns and spacing above the hotbar. The mastery talent tree provides each active skill's icon picker and preview alongside its animation selectors. Settings and icon filenames persist in the existing royal combat configuration; older configurations receive the compact defaults.

Players configure the ten slot bindings in **Settings → Controls** (two bindings per slot, default `Alt+1` through `Alt+0`). The character's keyboard path ignores these while typing, consumes held skill combinations before normal hotbar inputs, and activates a technique only on the initial key press. Mouse and keyboard share the same cooldown/pending/visibility guards. Each slot displays its configured key caption.

In **Weapon Masteries**, select one of the ten numbered slots, then use **Add to slot** beside a learned active talent, or **Clear selected slot**. Selection is saved by the server per character and weapon mastery category in `WeaponSkillLoadouts` inside the existing mastery SQLite database. Moving a skill clears its former slot; empty slots stay empty after reconnecting. New characters without saved layouts receive the previous automatic learned-skill ordering. Lost ranks or eligibility disable saved skills without granting access to them. Public mastery inspection exposes no layout editing controls.

The bar is available only with a local player on land, outside visible mini-games, blocking overlays and open game windows such as Daily Rewards. Window creation order does not affect this rule. Archery, fishing, Exportation, cooking, poker, blackjack, potions, roulette, dice, lockpicking, metalworking, jousting, duels and spectator mini-game views suppress it. Boarding a ship hides it; disembarking restores it if the equipped weapon has learned eligible techniques. Late cooldown/mastery packets cannot make it reappear while suppressed. Hidden controls also reject activation callbacks. Cooldown state remains synchronized while hidden.
